Village Plaza

Multifamiliar • 2014 • Location: Chapel Hill, NC, USA.

Overview

This is the first project to come under the town’s new form-based code rules for the retrofit of an existing suburban shopping center. This landmark project is expected to set the pace for other property owners in the 180-acre redevelopment district and create a more vibrant, walkable neighborhood.

The project proposes a strong brick base for amenities and retail and a series of alternating horizontal and vertical planes for the building middle and Top. The residential entry is articulated through an urban wedge that opens up the streetscape towards the vestibule and vertical tower. The building middle is articulated with a series of light and dark panel planes arranged in a pinwheel pattern to direct the views around the building.
